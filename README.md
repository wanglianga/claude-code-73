# 城市公交失物招领与监控调阅平台

## 原始需求

> 开发城市公交失物招领与监控调阅平台，可使用 Next.js、Go 和 PostgreSQL。乘客申报遗失手机、钱包、证件、背包或儿童物品时，平台收集线路、车辆、上车站、下车站、时间、座位位置、物品特征和联系方式。调度根据车辆 GPS、刷卡记录、司机排班和站点监控缩小范围；司机或保洁上交物品后，站务人员登记照片、存放柜、贵重程度和保管期限。若乘客描述不清、同类物品多件、司机未及时上交、监控需要审批、身份证件涉及隐私或物品逾期无人认领，平台要把乘客、客服、司机、站务、调度和安保放在同一招领单里处理。认领时，平台核验身份证、描述匹配、委托代领和签收照片；逾期物品按类型进入移交、销毁或捐赠流程。所有查找、调阅、上交和认领记录形成可审计链路。平台还要处理跨线路换乘后遗失、老人不会描述车牌、学生证件被同学代领、贵重物品报警和车队之间移交。客服答复乘客时，需要看到查找进度、物品保管状态和下一步责任人。如果失物涉及银行卡、药品、儿童证件或危险品，平台要触发不同保管规则和告知流程。逾期处置前，站务人员需要按物品类型完成公告、联系和移交确认。

## 技术栈与架构

- **前端**：Next.js 14（App Router，standalone 输出），端口 3000
- **后端**：Go 1.22（标准库 `net/http` + `lib/pq`），REST API，端口 8080（仅内部）
- **数据库**：PostgreSQL 16（仅内部网络，不发布宿主端口）
- 前端通过 Next.js rewrites 将 `/api/*`、`/uploads/*` 反代到 Go 服务，浏览器同源访问，Cookie（HttpOnly JWT）鉴权

```
浏览器 ──► web(Next.js, 发布端口) ──内部网络──► api(Go) ──► db(PostgreSQL)
```

## 一键启动

```bash
cp .env.example .env          # 可选，默认即可
docker compose up -d --build
```

启动后访问：`http://localhost:${CC_PUBLISH_PORT}`（默认 `http://localhost:3000`）。

- 验证环境约定：只有 `web` 服务发布端口（`${CC_PUBLISH_PORT}:3000`），`db`/`api` 不发布端口，仅在 compose 内部网络通过服务名互访。
- 取实际映射端口：`docker compose port web 3000`。
- 首次启动 `api` 会自动建表并写入演示数据（线路/站点/车辆/GPS/刷卡/排班/演示招领单与物品）。
- 停止：`docker compose down`（加 `-v` 清空数据重来）。

## 关键业务流（建议演示路径）

1. **申报**：`passenger` 登录 →「申报遗失」（可不选车牌，勾“记不清车牌”；可勾“跨线路换乘”）
2. **受理**：`cs` 登录 → 工作台点单号 →「受理并转调度排查」
3. **排查**：`dispatcher` 登录 → 招领单详情 → 用 GPS/刷卡/排班查出候选车辆 → 写排查记录并锁定车辆 →「申请监控调阅」
4. **审批**：`security` 登录 → 工作台批准调阅（涉隐私申请会标注）；处理贵重/危险品报警
5. **上交与登记**：`driver` 上交物品 → `station` 工作台「去登记」→ 填存放柜/贵重程度/照片 → 入库（特殊类别自动套用保管规则并触发报警）
6. **匹配**：`cs` 或 `station` 在招领单详情将在库物品与申报匹配 → 通知乘客
7. **认领**：`passenger` 在招领单详情「申请认领」（身份证核验 / 描述匹配 / 委托代领，如同学代领学生证）→ `station` 在物品详情核验 → 上传签收照片 → 物品出库、招领单完结
8. **逾期处置**：`station` 在逾期物品详情发起处置（按类型限定 移交/销毁/捐赠）→ 依次完成 公告 → 联系 → 移交确认 → 执行
9. **车队移交**：`station` 在物品详情发起移交 → 对方车队站务（`station2`）工作台确认接收
10. **审计**：每个招领单/物品详情底部展示完整审计链；`GET /api/audit` 可查全局审计

## 特殊物品保管规则（系统自动触发）

| 类型 | 保管期 | 规则与告知流程 |
|---|---|---|
| 银行卡 | 15 天 | 电话提醒挂失；逾期剪角销毁并留存影像 |
| 药品 | 7 天 | 冷藏柜 2-8℃；逾期按医疗废弃物规范销毁（双人） |
| 儿童证件 | 90 天 | 优先联系监护人并站内公告；逾期移交学校/公安 |
| 身份证件 | 90 天 | 隐私脱敏展示，调阅需审批；逾期移交公安 |
| 贵重物品 | 90 天 | 双人核验入保险柜，联动安保报警；逾期移交公安 |
| 危险品 | 3 天 | 不入柜，安保暂存 + 紧急报警；移交公安 |
| 普通物品 | 30 天 | 逾期公告后捐赠或销毁 |

## 验证方式

以“`docker compose up -d` 后各服务 healthy + 关键业务流可走通”为验收标准：

```bash
docker compose up -d --build
docker compose ps                      # db/api/web 均 healthy
PORT=$(docker compose port web 3000 | cut -d: -f2)
curl -s "http://host.docker.internal:$PORT/api/auth/me"   # 经 web 反代到 api，返回未登录提示即通
# 浏览器打开 http://localhost:$PORT ，按上表账号走一遍业务流
docker compose down
```
